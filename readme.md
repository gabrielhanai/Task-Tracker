# Task Tracker

O **Task Tracker** é um gerenciador de tarefas desenvolvido como projeto para a disciplina de Bootcamp II da faculdade. 

O requisito original do trabalho era criar apenas um programa com Interface de Linha de Comando (CLI) utilizando Python. No entanto, para colocar em prática os conhecimentos adquiridos no curso **CS50 de Harvard**, o projeto foi expandido e também conta com uma versão Web construída com **Flask**. 

Além do desenvolvimento, este repositório cumpre a etapa do trabalho de integrar o código ao GitHub.

---

## Funcionalidades

O sistema utiliza o método Kanban para organizar as demandas de maneira similar ao Trello. O usuário pode:
- **Adicionar tarefas** nas categorias:
  - **To Do** (A Fazer)
  - **Doing** (Fazendo)
  - **Done** (Concluídas)
- **Limpar as tabelas** para dar espaço a novas tarefas.
